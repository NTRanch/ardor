# Ardor

**Works of passion for passionate people.**

Ardor is NTRanch's game/app maker MCP server — one authoring surface
for building adult (18+) games and apps end to end: project
scaffolding, cast and canon, scenes and systems, kink-legitimate
dialogue as structured data, story and levels, content-safety
systems, asset routing, deterministic playtest QA, release handoffs
to 47 verified channels, and channel credential references (never
values). Modern MCP era only (2026-07-28); 46 tools.

- **Server (Rust, rmcp):** [`ardor/`](ardor/) — see
  [`ardor/README.md`](ardor/README.md) for the full tool map.
- **Companion (Kotlin):** [`ardor-companion/`](ardor-companion/) —
  modern-era MCP client plus the embeddable Android QA library.
- **Record:** [`BRIEF.md`](BRIEF.md) is the commission;
  `BUILD-REPORT.md`, `BUILD-REPORT-ANNEX.md`, and
  `BUILD-REPORT-STAGE2.md` are the gated build reports.
